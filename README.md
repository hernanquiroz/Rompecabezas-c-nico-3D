# 🧩 Rompecabezas cónico 3D — armar y desarmar

App interactiva con Streamlit + Plotly que modela un rompecabezas de madera
tipo cono/piña: tablillas ranuradas dispuestas radialmente que se encajan.

## Ejecutar localmente
pip install -r requirements.txt
streamlit run app.py

## Despliegue
Sube los archivos a GitHub → share.streamlit.io → New app → Deploy.
